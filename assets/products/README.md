Mahsulot rasmlarini shu papkaga qoʻying, keyin `index.html` ichidagi
`CONFIG.rasm` ga yoʻlini yozing. Masalan:

    rasm: { telefon: 'assets/products/iphone.png' }

Fon shaffof PNG eng yaxshi natija beradi. Rasm boʻlmasa chizma qoladi.

Put product photos here and point `CONFIG.rasm` at them. Transparent PNGs work
best; without a photo the board falls back to its drawing.
